# 0.2.3 本人文字来源与母群排除检查

日期：2026-10-21。目标：iOS 16.0.3、微信 8.0.76 / 8.0.79。编译和模拟测试不代表两版真机兼容。仍没有实际转发发送器或可用的执行按钮，预览确认只建立计划。

## 安装与入口

1. 用本轮新生成的 0.2.3 普通 DEB 替换旧插件，保留配置；完全结束微信进程后重新打开。
2. 从「我 → 设置 → SyncRelay 转发」进入，确认页头为 0.2.3；不要求开启悬浮。
3. 设置入口、读取账号或打开面板若异常，先停止本轮消息测试，回传截图、脱敏诊断及微信版本/构建号。闪退时停用插件并保留崩溃日志。

## 母群自动排除

1. 选择一个你有权测试的母群，记住其原始群 ID；同名群不代表同一个群。
2. 打开「搜索并排除群聊」，页面应提示「母群已自动排除」，手动排除数不需要加一。母群不会作为可勾选的普通目标出现。
3. 生成规则后查看目标明细，母群 ID 不应在任何规则中。取消全部手动排除后再次预览，母群仍不可成为目标。
4. 更换母群需确认清空旧草稿分组和来源成员；重新选择并生成后，新母群同样排除。已确认计划和旧执行历史不会随草稿改写。
5. 如果母群真的出现在规则目标明细，回传目标页与母群选择页截图；不要只凭同名或手动排除数判断，也不要开始真实发送。

## 本人文字来源

1. 「指定发送者」勾选「我（当前登录账号）」，核对其显示的 wxid；先只选本人，允许文字。成员列表暂不可读时也应有本人选项，页脚会说明其他成员不可读。
2. 建立至少一条目标规则并保存草稿，再点「等待一条母群文字」及确认开始等待。这些操作均不发送。
3. 关闭插件面板，回母群，由你手动发送一条普通文字，例如 `SyncRelay self test A`；保持微信在前台，不锁屏。
4. 回插件查看预览，核对实际正文、母群 ID、本人 wxid、`svr:` 开头的消息 ID。最多观察 30 秒；不应要求另找一个群成员代发。
5. 再发第二条不应替换已经锁定的第一条。确认只建立内容计划，不应向任何目标群发消息。
6. 分别测试：未勾选本人时本人消息不进入预览；错误群发的文字不进入预览；仅勾选本人时其他成员文字不进入预览。
7. 取消等待后发消息不采集；重新等待只使用本次代次。切后台/锁屏取消等待，回前台不自动重开。预览未确认前退出微信不保证保留。

若 30 秒内没有预览，复制「查看适配诊断」中的 `receiver` 部分，重点是 `ownTextHookAvailable`、`ownTextPending`、`ownTextState`、`problem` 及入口/getter 签名。报告不应包含 wxid、群 ID、正文或原始消息 ID。

- `awaiting_server_id`：已观察到本人文字，但还未取得服务器消息 ID。
- `source_candidate`：已形成候选；最终是否进入预览仍由已保存的发送者和消息类型过滤。
- `timed_out`：期限内未取得 ID；没有伪报捕获成功，也没使用临时本地 ID 作源 ID。
- `conflict`：原始消息对象的方向、发送者、类型、正文或已有本地 ID 改变，已拒绝本条。
- `unavailable`：本人发送入口不匹配或不可用；不能据此声称本人路径已适配成功。

本轮需要：0.2.3 页头截图、母群排除/规则目标核对结果、本人文字预览或超时诊断、实际微信版本/构建号。完整群数量、图片接收、真实转发、暂停/继续及常亮不在本轮验收范围。
