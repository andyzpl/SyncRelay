# 0.2.10 单群文字实验真机检查

本包只验证一次、一个授权目标群的文字提交；100/200 群规则、自动接力、暂停续传和图片发送仍未开放。iOS 16.0.3、微信 8.0.79.35 优先；8.0.76 仅为候选版本，不宣称本包已真机兼容。确切源码、CI run 和 SHA-256 写入交付目录的 `ci-provenance.json` / `SHA256SUMS`。

## 安装与设置

1. 备份微信及插件配置，完全退出微信，安装新版本普通 DEB，再按现有巨魔/越狱注入流程重载微信。数据库升级 v4 后，不要直接降级旧包。
2. 进入「我 → 设置 → SyncRelay 转发」。选择一个母群、一个来源 wxid（可选本人），只启用文字，选择一个不同的授权目标测试群建立规则，然后保存。
3. 点“等待源消息”，关闭面板回母群发一条新的短文字。进入预览，核对母群、来源 wxid 和正文。旧预览的设置有变化时，放弃并重新等待。
4. 不点“确认建立内容计划”，返回主设置；在更多设置开启“单群文字实验发送”。这不是之前需要回群手动发送的“只读观察”。

## 只发送一条

1. 在“源消息与计划”点“单群文字发送（实验）”，选一个规则内目标；母群和排除群不应出现。
2. 二次核对目标和文字，确认后等待至少 10 秒。期间保持本页、微信前台；取消或切后台不会自动恢复发送。
3. 提交后最多观察 30 秒，期间应保持自动锁屏禁用；完成后恢复之前的自动锁屏状态。“停止观察”不能撤回已提交消息，也不代表发送失败。
4. 在目标群人工核对：是否收到、是否只有一条、文字是否正确。页面的“已调用，送达待核对”或服务器 ID 不能替代这个检查。
5. 立即导出「更多设置 → 导出运行诊断」，告知目标群收到/未收到/不确定、页面提示和时间即可，不需提供真实 wxid 或正文。

## 安全边界与停止条件

- 每次微信进程最多一次主机提交，重新打开面板不会重置；同一条源消息跨重启也不能再次实验。未知结果不补发，不换第二个群继续试。
- 取消倒计时、门禁失败、切后台、手动锁屏或观察停止后，必须确认常亮请求已释放；不会阻止系统/用户手动锁屏，也不保证后台运行。
- ABI 不匹配、账号变化、闪退、无响应、错误目标、重复消息或结果不明时立即停止，先导出诊断。不扩大到批量群。
- 运行报告的 `singleTextSendCandidate`、持久占位概要及只读手动观察相互独立；`deviceVerified` 仍为 false，不伪报兼容或送达。
