# 设置入口设计记录

日期：2026-10-21。范围：为现有微信宿主增加只读适配与配置流程，不对微信整体视觉重新设计。

北极星：让用户先核对“哪个群、哪个 wxid、哪些目标”，再保存草稿；当前没有发送能力，不出现误导性的开始按钮。

## 本轮原生样式收拢（未完成真机视觉验证）

- 按用户指定的微信/Mikoto 原生列表方向，只做一个方向，不另造网页卡片或探索多套品牌风格。已有离线证据说明表构建方式，没有 Mikoto 页面截图，不能宣称逐像素复刻。
- 主设置、群/成员选择及计划/历史页统一为通栏 grouped 表格、浅灰背景、白色分组、细分隔线、标准小导航标题；深色随宿主 trait 切换，不强制主题。
- 主设置使用左名称/右当前值，按来源、节拍、规则、源消息、更多排序；诊断和观察下移，保留所有旧动作。普通字号为系统缩放字体，无障碍大字号回到上下两行，不压缩 wxid。
- 群/成员页仍显示名称和完整原始 ID；只读源正文保留账号核对与失活隐藏，不为美观移除身份/正文保护。原生导航推入、开关、勾选和保存反馈保留，不加装饰动画。
- 原有模态导航容器与未保存退出确认保持不变；只复制宿主导航栏 appearance 到插件自己的导航栏，不修改宿主导航栈、全局 appearance 或表代理。
- 删除首页重复的长说明、顶部版本 prompt；完整操作边界移到“使用说明”。开发版不发送、图片不可用、母群自动排除及锁屏取消仍有可见提示，版本移到末尾。
- 更多设置新增运行诊断与 JSON 导出。诊断从 UI 导出白名单概要，不序列化草稿或源消息。维护与脱敏约定见 `RUNTIME-DIAGNOSTICS.md`。

本地没有可运行 iOS UI/模拟器和目标截图，未验证实际视觉、动态字号布局或分享交互。未独立视觉评审，不评分；没有用网页示意图冒充插件截图。证据是源码和本地语法日志 `.build-cache/syntax-native-ui.log`，不是渲染验收。

## 历史实现记录

- 品类：微信内嵌配置工具；首屏主动作是确认来源与保存配置，不是营销或数据看板。
- 方向：沿用 iOS/微信设置语境，原生分组列表、标准导航、系统动态字体与语义颜色；不另造网页式卡片或品牌插画。
- 层级：适配状态、来源、间隔、目标分组、单条内容与计划；状态明确写出不发送和待核对限制。
- 成员/群信息：名称主行、原始 ID 次行，允许换行；搜索同时匹配两者，同昵称不作为身份判断。
- 动效：原生模态入场、导航推入/返回、点选与勾选反馈/开关过渡。遵循系统设置，不添加装饰性动画。
- 素材：本任务不需要照片、头像抓取或生成图；没有可帮助核对身份的图片证据，不加入占位头像。
- 减法：不展示虚假的发送成功数、完成时间或未实现的执行按钮。保存草稿与发送任务明确分开。
- 入口：0.2.1 用户实测未找到设置行。0.2.2 仍坚持「我 → 设置 → SyncRelay 转发」，修正新旧表管理器差异，增加出现/晚安装刷新；原生行不可用时仅在设置列表底部保留同名可点击恢复入口，保留原页脚，避免诊断不可达。无窗口强制浮窗、不替换 data source/delegate；只核对自身对象身份去重，不按标题猜别的插件行。
- 悬浮：默认关闭，面板内可开启且独立持久化；关闭立即移除，关闭面板不强行恢复。存储失败也可进入设置查看诊断/修改此开关，但不能编辑规则。
- 状态：读取失败、账号改变、未保存修改、配置保存成功/失败、不可用接口及空列表均有可见结果。
- 本轮增加：手动等待及取消、单条预览确认、已确认计划与规则/历史/异常只读页；仍沿用原生列表，不做视觉重设计。长正文在列表中仅给摘要，可推入完整只读查看；确认不开始发送。
- 正文保护：完整查看页离开活跃状态先隐藏正文，重新显示/回前台前重新核对账号；核对失败不展示旧正文。行为已编写，未做设备切换与视觉验证。
- 发送观察：适配状态区新增一次手动文字发送的只读观察，沿用已有单群搜索选择和二次确认；明确由用户回微信手动发送、120 秒、锁屏/切后台停止、不读正文/不代发/不判断成功。活动时可直接停止，仅在已主动开启悬浮入口且无预览时显示“观察”；也可一直从原生设置返回查看。
- 诊断快照：原诊断页增加脱敏观察报告和原始状态码，仍为打开时快照，不伪装实时发送进度；不展示账号/群/消息 ID，也不把观测次数标成成功数。

验证：代码做了动态字号、多行、自适应行高和原生搜索导航约束；已收到 0.2.0 群数量偏少和 0.2.1 主入口缺失的真实反馈。尚无 0.2.2 iPhone/模拟器画面，未验证本轮视觉、手势、前后台或无障碍表现。没有独立视觉评审，不评分；未生成冒充运行结果的截图。沿用现有视觉，没有增加装饰性动效或无关页面，也没有为修入口重复改正文案。新版设备清单见 DEVICE-CHECK-0.2.2.md。
