## 本轮行为

- 最低间隔为 3 秒；下限小于 3 或上限小于下限会被拒绝。
- 新建规则默认下限 5、上限 10 秒；上下限相同为固定间隔，上限仍可自定义。
- 已保存账号配置、已冻结计划和运行快照不会因覆盖升级被静默改写；需要改变时在设置页重新保存。
- schema 8 只兼容迁移旧 `rules` 间隔约束，保留计划、配置、历史、媒体和防重复占位。
