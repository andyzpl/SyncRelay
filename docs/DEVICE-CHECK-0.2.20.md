# 0.2.20 单条最多 20 群测试

本轮将真实执行范围从每条 1–3 群扩到 1–20 群。文字和静态图片共用范围限制；21 群及以上仍不开放发送，不会偷偷截取前 20 群。默认 100 群分组配置不变，旧计划与进度不重排。自动捕获与胶囊第二版不包含在本包中，仍使用现有等待源消息流程。

## 准备

1. 安装 0.2.20 后完全退出并重新打开微信，在“我 → 设置 → SyncRelay 转发”核对版本。
2. 使用授权测试群，手动选择 10–20 个目标群组成一条规则；数量不足可用实际数量，不必凑满。母群不作为目标。不要直接使用已有 100 群规则，也不要删除持久记录来重发旧消息。
3. 来源选母群和指定成员 wxid（可选本人），勾选文字/图片，保存。默认新规则 5–10 秒、最低 3 秒；旧设置不会被改写。

## 两轮发送

1. 第一轮：等待一条新的母群文字，确认内容计划，打开规则选择“开始小群测试”。无需启用旧单群实验开关。
2. 过程中回复其他聊天、查看视频号；进度不应因为离开设置页而停止。暂停一次，等待后继续，核对不重复发送。
3. 第二轮：使用新静态图片建立新计划，执行相同目标范围，核对图片内容一致、无漏错群或重复发送。
4. 正常执行结束后，检查完成状态、已处理数量和异常摘要。下一条规则不会自动开始。“已提交”不是可靠送达回执。

## 恢复

- 用单独的新消息测试切后台/锁屏：应停止新派发，回前台不自动发送，点击继续后只处理未尝试目标。
- 用单独的新消息测试重启：发送部分目标后退出微信，重开后手动继续未发；在途结果未知的目标不得盲目重发。
- 每次实际发送间隔从上一条结果处理完成后计时，包含接口检查时间，可能超过所设等待上限。
- 若异常，先暂停并导出运行诊断，附上文字/图片、目标数、操作过程及有无重复。正常使用不要求逐群点击确认。

编译和模拟通过不代表本轮 20 群真机已验收；微信 8.0.76 兼容性仍需单独验证。
