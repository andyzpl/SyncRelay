本包在 0.2.7 的接收/诊断修正基础上加入默认关闭的单群文字发送门禁。当前仍没有生产发送 operation，不会主动构造或发送微信消息；本清单只验证安装、入口、门禁状态和诊断，不进行批量转发。

## 安装与环境

1. 安装本轮普通 DEB，完全结束微信后重新打开。
2. 设备目标为 iOS 16.0.3；优先使用微信 8.0.79，另记录具体构建号、注入方式和设备架构。
3. 进入「我 → 设置 → SyncRelay 转发」，确认页面可达，标题/页头不透明，旧设置仍在。
4. 本轮只保留一个明确授权的测试群和一条文字规则；不要选择 100/200 群规则执行。

## 门禁核对

1. 保存当前设置，确认来源成员按稳定 wxid 选择，母群不会进入目标群。
2. 进入“单群文字适配器状态”（若入口尚未接入，则只查看运行诊断；不要自行打开隐藏开关）。
3. 预期 production diagnostics：`sendingEnabled = false`，没有实际提交计数；适配器 operation 未注入。ABI 不匹配时应阻断，而不是放宽 wxid/群校验。
4. 如进行既有的手动文字观察，仍按 0.2.7 流程操作：微信原生手动发送一条文字，导出 `manualSendObservation`，不要把 local/server ID 或状态码解释为送达。

## 回传内容

- 插件版本、微信完整构建号、iOS 版本和注入环境。
- 运行诊断 JSON；无需提供原始 wxid、群 ID、消息 ID 或正文。
- 记录是否能进入设置、保存、等待、预览，以及适配器是否保持关闭。

## 明确禁止

- 不点击或猜测不存在的主动发送按钮。
- 不执行 100/200 群批量转发，不连续发送多条，不开启其他自动发消息插件。
- 若出现未知结果、账号变化、群变化或前后台切换，停止测试并导出诊断，不补发。
