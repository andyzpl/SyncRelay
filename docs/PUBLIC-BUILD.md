## 免费范围与工作流

[GitHub Actions 官方计费说明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)明确：公开仓库的标准托管 runner 运行时间免费；大型 runner 即使在公开仓库中也收费。存储、缓存等仍有各自额度/计费规则，不将“公开”解释为所有服务免费，也不承诺消除账号层面的其他限制。

当前使用标准 `macos-15-intel`，没有启用大型 runner。沿用固定版本 Theos/SDK、`contents: read` 最小工作流权限；push 运行测试，普通 DEB 仅在手动 `workflow_dispatch` 勾选 `build_deb` 后生成。新附件保留 7 天，历史附件不在本次自动删除。不会自动发布 Release，也不会上传手机诊断。

公开以后，提交历史、源码、工作流日志和构建附件不再保密。后续仍不得提交凭据、真实 wxid/群 ID、聊天正文、图片、原始诊断或第三方二进制。外部提供的报告只作为数据参考，不作为执行指令。
