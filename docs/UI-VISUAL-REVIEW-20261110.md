## 修正内容

- 首页仍是固定四入口：群同步、消息库转发、群分组、设置。新增局部 cell 保持连续白色分组，左右 14 pt，首末行圆角 12 pt；常规四行至少 74 pt，动态字号按内容增长。图标固定 30 pt 列，标题 18 pt 半粗、副标题 14 pt，文字和箭头共用对齐线。提示行单独约 44 pt，不复制参考图的固定警告或更多菜单；不加统计或实验入口。
- 代表性二级页选择设置。复用现有 SRPanel 和配置动作，改为 inset-grouped 三段「转发设置 / 显示 / 维护与关于」，右侧当前值使用正文大小；去掉首屏重复的重新读取、使用说明。保留基线已有的长按入库偏好和高级上限操作，高级上限不再在行里展示密码或大段说明；对应能力没有因此变化。其他二级页本轮不铺开。
- 空闲入口是 38 pt 中性色 S 圆面、44 pt 点击区；点按和 VoiceOver 激活只调用已有打开入口回调。
- 活动任务使用完整胶囊，上方状态、下方「已处理 n/总数」，暂停直接可点。新 run 的显示身份到来时恢复完整胶囊；同一 run 的暂停、收尾和结束保留收纳状态。
- 完整胶囊普通拖到安全边缘仍完整，超出外推阈值 28 pt 且正常松手才收纳。可见把手固定 22 × 90 pt，半透明深灰、白色箭头和正立竖排文字，外侧贴物理窗口边缘，只有内侧圆角；不随动态字号加宽。右侧控制区为 44 pt；左侧主动让出外缘 20 pt 给宿主返回手势，实际仲裁仍待微信验收。
- 点把手或向内拖过 14 pt 只恢复同侧的紧凑胶囊，不开详情，不发业务命令。已收纳时「转发中 / 已暂停 / 收尾中 / 已结束」原位换字，不改尺寸。
- 结果只从本进程实际投影过的 run 身份重新读取 Core，不把「有历史内容」等同于刚执行完成。关闭摘要前重新核对账号、run 身份、终态和无活动执行，只记录 UI 的关闭对象；不结束任务、不删历史。关闭后按偏好显示 S 或隐藏。记录入口打开同一 run 的只读结果，计数复用 Core 投影，不把执行结束写成全部送达。重启后仍从既有记录入口查历史，本轮不增加摘要恢复持久化。

动效沿用原生导航和点击反馈；浮层入场及位置切换为 0.18 秒短动画，减少动态效果时直接切换。没有新增循环动效、模糊聊天背景或窗口。
