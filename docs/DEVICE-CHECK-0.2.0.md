# 0.2.0 设备验证清单

此版本不接收母群消息、不发送、不自动建立任务，不需要用真实大批量群发测试。
目标 iOS 16.0.3，微信 8.0.76 / 8.0.79；两版分别验证。不要把 macOS 模拟测试视作微信兼容性证明。

## 安装与入口

1. 使用现有工具将普通 DEB 加载到微信。结束微信进程后重新打开。
2. 登录后观察右下方“同步”入口，点击进入。若完全没有入口，记录微信版本及构建号、注入方式和截图，不反复尝试发送。
3. 本版浮动入口是诊断期入口，不修改微信设置页面；设置采用原生全屏导航，点“关闭”返回微信。

## 先核对只读数据

1. 顶部显示的账号原始 ID 是否为当前账号；读取失败时，打开“查看适配诊断”，点“复制”回传。
2. 选择母群，核对群名和群 ID；记录列出的群数量。当前接口可能只覆盖部分群，不把“全选”理解为微信所有已加入群。
3. 指定发送者，核对原始 wxid；同昵称的两个人是否显示不同 ID。昵称缺失时显示原始 ID，不猜昵称。
4. 若群成员读取失败，先在微信打开母群，再返回重试；仍失败则提供诊断，不手工绕过稳定 ID 检查。

## 验证配置草稿

1. 勾选文字/图片，关闭最后一项时应被阻止。
2. 设置 10–20 秒并保存；9–20、20–10 或非整数输入应被拒绝。
3. “搜索并排除群聊”：按名称或 ID 搜索后勾选排除；“排除搜索结果/恢复搜索结果”只修改当前匹配项；“排除全部可选群/取消全部排除”作用于完整列表。零个排除也能应用。
4. “自动分配规则”：两个输入框分别标明 100 群/条、200 群/条。各填 10，在群足够时预览 20 条/3000 群；检查实际可分配、缺口和剩余，点取消不得改变草稿。
5. 数量不足时仍能预览和确认，只保留实际有目标的规则，最后一条可不足额。全部排除时提示无新增规则，不创建空规则。
6. 确认生成后查看任意规则，所有规则共用母群、wxid、类型和间隔；修改一次统一条件后，不需逐条设置。重复生成须自动排除之前分配的群和母群，保留原规则。
7. 用“手动选择并分组”全选超过 200 个可选目标，应按每条不超过 200 群拆分，不产生一个超大批次；该入口全选作用于完整可选列表，不限搜索结果。
8. 新增排除命中已有规则时，应确认移除目标数和空规则数；取消不改变任何草稿。应用后其他规则不自动重排，解除排除也不自动补齐。
9. “保存草稿”，关闭再打开，应恢复统一来源、发送者、类型、间隔、排除群与分组。旧版无排除字段的草稿应仍能读取；从本地群列表临时消失的排除项仍应保留。
10. 修改后关闭，选择继续编辑应保留输入；选择放弃应保留最后一次已保存的草稿。
11. 更换母群时，有发送者或分组应先确认清空；取消保持原配置，排除列表不因更换母群被清空。
12. 删除未执行分组后，其中未排除目标可以重新分配；保存后重新打开核对。
13. 切换微信账号后，旧面板操作或旧分配预览应停止；关闭重开后读取新账号草稿，不能覆盖旧账号配置。

## 视觉与交互检查

- 小屏、长群名、长 wxid、较大系统字号下无按钮遮挡和关键信息裁切。
- 搜索、选择勾号、导航返回、保存反馈正常；打开/关闭设置不影响微信原功能。
- 自动分配的两个数字框标签清楚，预览内容可完整阅读；大字号、长群 ID 下确认/取消均可用。
- 本轮开发环境没有 iPhone 画面，未完成真机视觉/交互验收；请提供设置首页、选群、成员页及错误页截图。

诊断报告只包含系统/微信版本、接口签名与固定提示，不含账号 wxid、群名单或消息内容。截图中的个人 ID 请按需要遮盖。
本版不需要启用防锁屏；常亮只会在未来真正执行批次时开启。
