# 0.2.18 节奏调整真机检查

本包只调整发送节奏约束，不扩大 0.2.17 已验证的 1–3 个授权群范围。覆盖安装后完全退出并重开微信，确认设置页显示 `0.2.18`；不要降级回旧包。数据库 schema 8 会兼容迁移旧的 `rules` 间隔约束，保留计划、配置、历史和媒体。

## 设置与校验

1. 新账号或清空后的新规则应显示默认下限 `5`、上限 `10` 秒。
2. 输入 `3`–`3` 并保存，设置应成功，表示固定 3 秒节奏。
3. 输入下限 `2`（例如 `2`–`10`）并保存，设置应拒绝且保留此前有效值。
4. 输入上限小于下限应拒绝；上限可以继续自定义，但不得小于下限。
5. 已有自定义配置不应在覆盖升级后被静默改写。需要改变时在设置页重新保存。

## 小群回归

使用一条新的母群文字或静态图片消息，选择 1–3 个已授权目标群，按现有 0.2.17 流程开始一次规则。核对首次提交前等待时间、暂停/继续、切后台或锁屏暂停、重启后的 pending-only 继续，以及完成时间和失败/未知汇总。不要把节奏等待本身当成送达成功证据，也不要直接用 100/200 群做本轮首次验证。

## 反馈

反馈请包含：插件版本、微信版本、设置的下限/上限、规则目标数量、实际开始/暂停/结束时间，以及导出的脱敏诊断。不要发送账号 wxid、群 ID、消息 ID 或正文。
